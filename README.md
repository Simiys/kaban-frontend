# 🎯 Kaban X – Frontend

Современное веб-приложение для управления проектами с использованием Kanban-досок. Позволяет командам эффективно организовывать работу, отслеживать задачи и управлять проектами в удобном визуальном интерфейсе.

## 🚀 Установка и запуск

### Локальная разработка

#### 1. Клонирование репозитория

```bash
git clone <repository-url>
cd kaban-frontend
```

#### 2. Установка зависимостей

```bash
npm install
```

#### 3. Настройка переменных окружения

Создайте файл `.env` в корне проекта (опционально):

```env
VITE_API_BASE_URL=http://localhost:8000
```

Если переменная не указана, по умолчанию используется `http://localhost:8000`.

#### 4. Запуск dev-сервера

```bash
npm run dev
```

Приложение будет доступно по адресу: **http://localhost:5173**

#### 5. Сборка для production

```bash
npm run build
```

Собранные файлы будут находиться в папке `dist/`.

#### 6. Предпросмотр production сборки

```bash
npm run preview
```

---

### Docker

#### Быстрый запуск

```bash
# Сборка и запуск через Docker Compose
docker-compose up -d --build
```

Приложение будет доступно по адресу: **http://localhost:3000**

#### Ручная сборка Docker образа

```bash
# Сборка образа
docker build -t kaban-frontend .

# Запуск контейнера
docker run -p 3000:80 kaban-frontend
```

#### Остановка контейнера

```bash
# Остановка через Docker Compose
docker-compose down

# Или остановка конкретного контейнера
docker stop kaban-frontend
```

## 🎯 Основные функции

### Страницы приложения

#### 🔐 Страницы аутентификации

- **`/`** или **`/login`** — страница входа

## 🔌 API интеграция

Приложение взаимодействует с backend API через хук `useApi`. Основные endpoints:

### Аутентификация
- `POST /auth/login` — вход в систему
- `POST /auth/register` — регистрация
- `GET /auth/activate` — активация аккаунта
- `POST /auth/refresh` — обновление токена

### Пользователи
- `GET /user/me` — получение текущего пользователя

### Команды
- `GET /teams` — список команд
- `POST /teams` — создание команды

### Проекты
- `GET /projects` — список проектов
- `POST /projects` — создание проекта
- `GET /projects/:id` — получение проекта
- `GET /projects/:id/board` — получение доски проекта

### Секции (колонки)
- `POST /projects/:id/sections` — создание секции
- `PATCH /projects/:id/sections/:sectionId` — обновление секции

### Задачи
- `POST /projects/:id/tasks` — создание задачи
- `PATCH /projects/:id/tasks/:taskId` — обновление задачи

### Авторизация

Все запросы (кроме аутентификации) требуют JWT токен в заголовке:
```
Authorization: Bearer <access_token>
```

Токены автоматически обновляются при истечении срока действия.

## 💻 Разработка

### Доступные команды

```bash
# Запуск dev-сервера
npm run dev

# Сборка для production
npm run build

# Предпросмотр production сборки
npm run preview

# Проверка кода линтером
npm run lint
```

### Работа с кодом

1. **Создание компонентов** — добавляйте новые компоненты в `src/components/`
2. **Создание страниц** — добавляйте новые страницы в `src/pages/` и регистрируйте маршруты в `App.tsx`
3. **Работа с API** — используйте хук `useApi()` для всех запросов к серверу
4. **Стилизация** — используйте Material-UI компоненты и кастомные CSS файлы

### Типизация

Проект полностью типизирован с помощью TypeScript. Все типы для API находятся в `src/hooks/useApi.ts`.
